# Controle de Gastos API 💰

## 💻 Sobre o Projeto

API REST desenvolvida para o gerenciamento e controle de finanças pessoais e gastos. Este projeto foi criado com o objetivo principal de praticar e aprofundar os conhecimentos no ecossistema **Spring Framework** utilizando **Java 21**.

> 🚧 **Status do Projeto:** Em construção. A estrutura inicial já está configurada e os *endpoints* serão implementados nas próximas etapas.

## 🚀 Tecnologias Utilizadas

* **Java 21**
* **Spring Boot**
* **Spring Web** (para criação da API REST)
* **Maven**
* **Banco de Dados em Memória**

## 📦 Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:
* [JDK 21](https://oracle.com)
* Uma IDE de sua preferência (IntelliJ IDEA, Eclipse, VS Code, etc.)
* Git

## 🔧 Como executar o projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/NatanaelGui/fincontrol.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd fincontrol
   ```

3. **Execute a aplicação:**   
   ```bash
   ./mvnw spring-boot:run
   ```

A aplicação iniciará por padrão em `http://localhost:8080`.
